# Reverse String

## Prompt

Crea una página web con lógica en javascript que invierta el orden de una cadena de texto. Por ejemplo: si introduzco AI4Devs devuelve sveD4IA.
El código debe de estar separado en dos archivos **index.html** y **script.js**. Separa la implementacion en dos archivos.

El archivo **index.html** debe contener:

- Titulo: Reverse String
- Campo Texto: Aqui se introduce el string al cual se le aplicará el reverse string.
- Boton "Reverse": Este boton realizara la conversion del string.
- Label: Aqui se mostrara el resultado del Reverse String.
- Boton "Copy": Permite copiar el resultado del reverse string.
- Realizar una pagina web moderna y con buenas practicas.

El archivo script.js debe contener:

- Contener la lógica de programación.
